API manual

Only POST query is supported with following calls:

getAnsibleList

Ansible inventory query will return with a JSON object that contains all metadata from the inventory. Eg.: POST Form "query=getAnsibleList" or JSON {"query":"getAnsibleList"}

getAnsibleHost

Ansible inventory query will return with a JSON object that contains all metadata about one host specified in the hostname parameter. Eg.: POST Form"query=getAnsibleHost&hostname=ansible.local.net" or JSON {"query":"getAnsibleHost","hostname":"qa-jenkins-master"}'

getGroups

General query will return with a JSON object that contains all group with group's variable and host members. Eg.: POST Form"query=getGroups" or JSON {"query":"getGroups"}

removeHostFromInventory

General query will remove server from the inventory and return with a JSON object that contains the confirmation. Eg.: "query=removeHostFromInventory&hostname=ansible.local.net" or JSON {"query":"removeHostFromInventory","hostname":"ansible.local.net"}

removeHostFromGroup

General query will remove server from a host group specified in the paramters and return with a JSON object that contains the confirmation. Eg.: "query=removeHostFromGroup&hostname=ansible.local.net&group=Production" or JSON {"query":"removeHostFromGroup","groupname":"this_hostgroup","hostname":"ansible.local.net"}

addHostVar

General query will add new variable to a server or update existing one specified in the paramters. It returning with a JSON object that contains the confirmation. Eg.: "query=addHostVar&hostname=ansible.local.net&hostvar=Variable1&value=NewValue"

addGroupVar

General query will add new variable to a host group or update existing one specified in the paramters. It returning with a JSON object that contains the confirmation. Eg.: "query=addGroupVar&group=Production&hostvar=Variable1&value=NewValue"
